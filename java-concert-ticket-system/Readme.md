# Java Concert Ticket System

This project contains three basic Java programs. Each part is written in a separate file.

---

## Part 1: Username Checker

File: Part1UsernameChecker.java

This program:

- Takes two username inputs
- Prints the length of each username
- Checks if the lengths match
- Checks if the strings match

---

## Part 2: Ticket Categories

File: Part2TicketCategories.java

This program:

- Takes 10 ticket category names
- Stores all entries in an ArrayList
- Stores unique entries in a HashSet
- Counts occurrences using a HashMap

---

## Part 3: Popular Merchandise

File: Part3PopularMerchandise.java

This program:

- Reads a CSV file named items.csv
- Splits the items
- Counts how many times each item appears
- Finds the top three most common items using basic loops and a HashMap
