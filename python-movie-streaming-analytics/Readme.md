# Python Movie Streaming Analytics

This project contains three basic Python programs. Each part is written in a separate file.

---

## Part 1: Password Validator

File: `part1_password_validator.py`

This program:

- Takes two password inputs
- Prints the length of each password
- Checks if the lengths match
- Checks if the strings match

---

## Part 2: Genre Preferences

File: `part2_genre_preferences.py`

This program:

- Takes 10 movie genres as input
- Stores all entries in a List
- Stores unique entries in a Set
- Counts occurrences of each genre using a Dictionary

---

## Part 3: Top Watched Movies

File: `part3_top_watched_movies.py`

This program:

- Reads a CSV file named `watchlist.csv`
- Splits movie titles
- Counts how many times each title appears
- Finds the top three most watched movies using simple loops and a dictionary

---
